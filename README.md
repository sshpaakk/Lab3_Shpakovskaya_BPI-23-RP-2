Лабораторная работа №3

Выполнила: Шпаковская Софья
Группа: БПИ-23-РП-2

Разработано веб-приложение «Доска публикаций», позволяющее загружать публикации с сервера и создавать новые.

Для работы с данными используется тестовый API JSONPlaceholder.

Приложение реализовано на HTML, CSS и JavaScript без использования дополнительных библиотек и фреймворков.

Функциональность

1. Загрузка пяти публикаций с помощью GET-запроса.
2. Отображение заголовков и текстов публикаций через DOM.
3. Создание публикации с помощью POST-запроса.
4. Проверка заполнения полей формы.
5. Отображение сообщений о загрузке, успехе и ошибках.
6. Блокировка кнопок во время выполнения запросов.
7. Обработка ошибок HTTP и сетевых сбоев.

Структура проекта

* index.html — интерфейс приложения.
* style.css — оформление страницы.
* app.js — логика приложения и HTTP-запросы.
* README.md — описание проекта.

Запуск приложения

1. Скачать или распаковать папку проекта.
2. Открыть проект в Visual Studio Code.
3. Запустить index.html через расширение Live Server.
4. Нажать кнопку «Загрузить публикации» для получения данных.
5. Для создания публикации заполнить поля «Заголовок» и «Текст» и нажать «Создать публикацию».

Для выполнения HTTP-запросов необходимо подключение к интернету.

Результаты проверки

1. GET-запрос: успешно загружены пять публикаций, HTTP 200.
2. POST-запрос: публикация успешно создана, HTTP 201, ID 101.
3. Пустые поля: отображается сообщение об ошибке.
4. Ввод только пробелов: отправка формы блокируется.
5. Ошибка HTTP 404: отображается сообщение об ошибке, кнопка остаётся доступной.
6. Сетевая ошибка: отображается сообщение об ошибке, повторный запрос возможен.
7. Проверка через DevTools: GET- и POST-запросы выполняются корректно.
8. Интерфейс: публикации и форма отображаются корректно, страница работает без перезагрузки.

JSONPlaceholder имитирует создание публикаций, поэтому новые записи не сохраняются на сервере постоянно.
